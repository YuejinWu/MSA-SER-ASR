1. 研究背景与目标

核心问题

如何利用大规模预训练模型的通用声学知识，在小规模多源情感数据上实现可靠的情感识别， 并构建情感识别 + 内容转录一站式服务？

核心挑战
  • 情感语音标注成本高，开源数据集规模小（合计 ~1 万条）
  • 情感表达跨多个时间尺度：毫秒级音色 ↔ 秒级韵律轮廓
  • 跨说话人、跨数据集泛化 — 声纹与情感特征需解耦
  • 类别间声学边界模糊（恐惧↔悲伤，开心↔愤怒）

3a. 核心算法 — 多尺度双分支建模

🔍 CNN 局部分支 — 捕捉短时频谱纹理

Conv1d(768→384, k=5, s=2) → ReLU → MaxPool(k=2) Conv1d(384→384, k=3) → ReLU → AdaptiveAvgPool(1) ⇒ 输出: (B, 384)

两层卷积提取局部 n-gram 声学模式（音素过渡、爆破音等），AdaptiveAvgPool 聚合为固定维度，侧重毫秒级微观纹理。

🌐 Attention 全局分支 — 建模长距离韵律

Q=Linear(768→64)(x) K=Linear(768→64)(x) A=softmax(Q·Kᵀ/√64) O=A@x ⇒ mean(O,dim=1) ⇒ 输出: (B, 768)

缩放点积自注意力，Q/K 压缩 12× 降低计算量，输出可解释逐帧权重，侧重秒级宏观韵律。

🔗 特征融合策略

CNN (384) + Attention (768) → Concat → 1152 → 768 → Do(0.4)×2 → Linear→6

双 Dropout 串联 ≈ 64% 失活率，对 7,000 训练样本正则化效果显著

3b. 核心算法 — Adapter 参数高效微调

🔌 Adapter 结构

Adapter(x) = Wup · GELU(Wdown · x) + x
W_down: 768 → 64 (瓶颈压缩 12×) W_up: 64 → 768 bottleneck = 64 · 近零初始化 N(0,1e-8)
  • 注入位置：WavLM 每层 Transformer 之后（共 12 个）
  • 残差连接：hidden + adapter(hidden)
  • 近零初始化确保训练初期行为 ≈ 冻结模型，避免梯度震荡

★ 核心增益

Adapter 相比纯冻结：准确率 67.6% → 73.1%（+5.5pp）
仅 1.2M 可训练参数实现最大单一增益，训练极其稳定。

Adapter 优势：效率 · 效果 · 稳定性 三角最优平衡

全微调 (94.4M) 易灾难性遗忘 → 解冻最后 N 层 (~32M) 梯度扰动大 → Adapter (1.2M) 仅学习任务适配增量，完美保留预训练声学知识

5c. 训练结果 — 混淆矩阵分析

图5-4：6×6 混淆矩阵（归一化）

🎯 混淆模式总结

  • 恐惧 → 悲伤（~30% 的错误）
    两种低唤醒情感声学空间重叠，高频颤抖特征在 5s/16kHz 下保留有限
  • 悲伤 → 中性（~20% 的错误）
    低强度悲伤与中性陈述边界天然模糊，CREMA-D 尤为明显
  • 开心 → 愤怒（~15% 的错误）
    高强度开心与愤怒的能量-语速-音高轮廓高度相似

关键发现

  • 中性（86.0%）和愤怒（87.2%）Recall 最高
  • 悲伤（51.6%）和恐惧（62.8%）Recall 最低
  • 高置信度错误（>0.9）非随机噪声，反映系统性偏差
  • 低唤醒情感的区分仍是 SER 领域固有难题

5d. 训练结果 — 特征空间 & 注意力可视化

图5-5：融合特征 t-SNE 二维投影（1,000 随机样本）
  • 中性（灰色）形成最紧凑簇 → 与高 Recall 一致
  • 愤怒+开心相对独立但部分重叠 → 混淆矩阵吻合
  • 恐惧+悲伤大面积混杂 → 低唤醒高混淆率
  • 6 类形成可辨识聚类结构 → 模型学到了判别性特征
图5-6：Temporal Attention 逐帧权重分布
  • 正确样本：注意力在话语中段（0.5–3.5s）显著高于首尾
  • 错误样本：注意力分散或过度集中个别短帧
  • 愤怒：注意力尖峰突出（爆发性发音）
  • 中性：注意力分布平坦均匀
  • Temporal Attention 提供模型可解释性

6. 对比实验汇总

实验骨干微调方式损失函数AccMacro F1结论
E0HuBERT冻结CE69.3%0.661单数据集基线（8类，仅参考）
E1HuBERT冻结CE+LS67.6%0.669多数据集→难度增，泛化更强
E2HuBERTAdapter(64)CE+LS73.1%0.729★ Adapter 核心增益 +5.5pp

E4WavLMAdapter(64)CE+LS73.5%0.732★★★ 最优方案

核心发现

  • Adapter 最大单一增益：冻结→Adapter +5.5pp
  • WavLM 略优于 HuBERT：+0.4pp，去噪预训练带来情感敏感
  • Focal Loss 未获益：γ=2.0 在小数据上放大噪声影响
  • 数据多样性 > 模型复杂度：三数据集冻结 F1(0.669) > 单数据集微调(0.661)

经验教训

  • 先建立稳固简单基线，再以最小增量迭代改进
  • 数据工程是性能提升的最大杠杆（960→7,051 条，扩大 7.3×）
  • Adapter 在效率—效果—稳定性三角中达到最优平衡
  • Curriculum Learning 隐蔽交互错误 → 简单方案更可靠

7. 语音识别集成 — Whisper ASR

🎤 Whisper 引擎

  • 模型：OpenAI Whisper base（~140MB）
  • 能力：多语言语音→文本转录 + 时间戳 + 语言检测
  • 输入：16kHz 单声道音频，任意长度
  • 输出：分段文本 + [start, end] 时间戳 + 语言标签
import whisper model = whisper.load_model("base") result = model.transcribe("audio.wav") # → {text, segments[{start,end,text}], language}
